Territory Management Documentation

Data Model Overview

The territory management system is designed to organize addresses into multiple, independent hierarchical trees (e.g., an "Electoral" tree, an "Administrative" tree).

  • NestedTerritory: The core model for the hierarchy, using django-mptt. Each node in the tree has a name, type (Country, Province, Region, etc.), and a tree_name to identify which hierarchy it belongs to.
  • Address: Your standard address model, containing geocoding information (latitude, longitude, and a location point).
  • AddressTerritoryLink: This is the crucial link between the other two models. It's a "through" model that creates a many-to-many relationship, allowing a single Address to be linked to multiple leaf nodes in different trees.

Data Sources

The base hierarchies are built from official geographical shapefiles. The primary source for Canadian census and electoral boundaries is Statistics Canada.

Source for Canadian Geographical Shapefiles: Statistics Canada 2021 Census Boundary Files

Management Scripts

The territory system is managed via a series of command-line scripts. They should be run in the following order:

1. Build Base Hierarchy

Script: build_base_hierarchy.py

Purpose: Creates the foundational levels of a new tree (Country, Province, Region) from shapefiles. This is a destructive operation for the specified tree only.

Usage:

python manage.py build_base_hierarchy [province_shapefile] [region_shapefile] --tree-name [TREE_NAME] [options]

Example:

python manage.py build_base_hierarchy DL/geodata/lpr_000b21a_f/lpr_000b21a_f.shp DL/geodata/lcef000b21a_f/lcÇf000b21a_f.shp --tree-name Electoral --prov-name-field PRNOM --prov-code-field PRIDU --region-name-field CÉFANOM --region-code-field CÉFIDU --region-parent-field PRIDU

2. Validate Coverage (Optional but Recommended)

Script: validate_shapefile_coverage.py

Purpose: Analyzes the base hierarchy in the database to calculate the percentage of each province's area that is covered by its child regions. This helps identify gaps in your shapefile data.

Usage:

python manage.py validate_shapefile_coverage

3. Place Addresses in Tree

Script: place_addresses_in_tree.py

Purpose: Links addresses to the leaf nodes of a specified, pre-existing tree. It uses efficient spatial queries to find all addresses that fall within the boundary of each leaf node.

Usage:

python manage.py place_addresses_in_tree [TREE_NAME]

Example:

python manage.py place_addresses_in_tree Electoral
